## 一、架构图概述

本架构图是面向**产品交付和解决方案团队**的燃气专题应用架构图，展示了松原市燃气安全监管平台的完整技术架构和功能模块。

### 设计特点

1. **细粒度展示**：功能点级别的详细展示，便于产品交付和方案设计
2. **分层清晰**：从展示层到数据层，层次分明
3. **领域驱动**：基于DDD思想，按业务领域划分模块
4. **技术完整**：包含完整的技术栈和中间件
5. **标注核心**：用⭐标注核心功能模块

## 三、各层详细说明

### 3.1 展示层（6个模块）

| 模块 | 说明 | 技术栈 |
|------|------|--------|
| PC管理端 | 后台管理系统 | Vue3 + Element Plus |
| 移动端APP | 巡检作业、现场处置 | uni-app |
| 综合态势大屏 | 全市燃气安全态势 | Cesium + ECharts |
| 燃气专题大屏 | 风险四色图/预警一张图 | Vue3 + ECharts |
| GIS一张图 | 燃气安全预警GIS展示 | OpenLayers/Cesium |
| 系统首页 | 工作台、待办、快捷入口 | Vue3 + Element Plus |

### 3.2 核心业务层（4个子系统）

#### 3.2.1 动态监测与报警子系统（橙色）

包含6个功能模块：

1. **燃气实时监测**
   - 地下空间可燃气体浓度监测
   - 燃气管网振动监测
   - 燃气管网压力监测
   - 监测数据实时展示/历史查询

2. **燃气安全监测报警**
   - 可燃气体浓度报警
   - 管网振动报警
   - 管网压力报警
   - 报警规则配置/阈值管理

3. **燃沼辨识分析** ⭐核心
   - 燃气泄漏特征识别
   - 沼气聚集特征识别
   - 多源数据融合分析
   - 辨识结果置信度评估

4. **燃气管网泄漏预警**
   - 泄漏预警模型
   - 泄漏预警发布
   - 预警等级分级

5. **沼气聚集预警**
   - 沼气聚集预警模型
   - 沼气聚集预警发布
   - 处置建议生成

6. **预警联动处置**
   - 预警工单自动生成
   - 预警工单派发
   - 预警工单处置
   - 预警工单审核
   - 预警处置统计/考核

7. **燃气安全预警GIS一张图**
   - 泄漏预警空间分布
   - 沼气预警空间分布
   - 预警实时态势展示
   - 周边监测数据对比分析
   - 预警影响范围分析
   - 预警GIS可视化

#### 3.2.2 风险评估子系统（橙色）

包含4个功能模块：

1. **燃气管网风险评估**
   - 风险评估模型配置
   - 风险因子识别
   - 风险等级评估
   - 风险评估清单
   - 风险详情查看

2. **管线风险四色图** ⭐核心
   - 红色-重大风险
   - 橙色-较大风险
   - 黄色-一般风险
   - 蓝色-低风险
   - GIS地图渲染展示

3. **风险分级管控**
   - 管控措施配置
   - 巡检频次设置
   - 管控措施执行
   - 管控效果评估
   - 管控措施调整

4. **风险统计分析**
   - 风险等级分布统计
   - 区域风险分布统计
   - 管材风险分布统计
   - 管龄风险分布统计
   - 风险趋势分析
   - 风险对比分析
   - 风险报表生成
   - 可视化图表展示

#### 3.2.3 辅助支持子系统（绿色）

包含6个功能模块：

1. **燃气安全知识库**
   - 知识分类管理
   - 知识内容维护
   - 知识检索查询

2. **法规标准库**
   - 法规分类管理
   - 标准规范维护
   - 法规检索查询

3. **案例库**
   - 事故案例录入
   - 案例分类管理
   - 案例检索分析

4. **消息通知**
   - 站内消息、短信通知、APP推送
   - 微信通知、邮件通知

5. **系统日志与审计**
   - 操作日志、登录日志
   - 安全审计、数据变更追溯

#### 3.2.4 泄漏研判分析子系统（粉色-高级功能）

包含4个功能模块：

1. **泄漏检测分析**
   - 多源数据融合分析
   - 泄漏特征识别
   - 泄漏概率计算

2. **泄漏定位**
   - 管段定位算法
   - 泄漏点精确定位
   - GIS空间展示

## 五、使用说明

### 5.1 如何打开

1. 使用 **draw.io** 桌面版或在线版打开
2. 访问 https://app.diagrams.net/
3. 选择 "Open Existing Diagram"
4. 选择 `燃气专题应用架构图.drawio` 文件

### 5.2 如何导出

1. **导出为PNG图片**：File → Export as → PNG
2. **导出为PDF**：File → Export as → PDF
3. **导出为SVG**：File → Export as → SVG

### 5.3 如何编辑

1. 双击任意文本框可编辑内容
2. 拖动元素可调整位置
3. 右键元素可修改样式
4. 使用 Ctrl+C / Ctrl+V 复制粘贴元素
