## 一、项目概述

### 1.1 项目背景

松原市燃气安全监管平台是城市生命线安全工程的核心组成部分，旨在建立覆盖全市的燃气安全监测、预警、处置、应急调度一体化管理体系。平台将作为城市燃气运行的"神经中枢"，实现对生命线系统风险的**可知、可感、可控、可预测**。

### 1.2 建设目标

| 目标 | 描述 | 关键指标 |
|------|------|----------|
| **全面感知** | 燃气管网、场站、用户侧的全方位实时监测 | 设备在线率≥99% |
| **智能预警** | 基于多源数据融合的风险识别和预警 | 预警准确率≥95% |
| **协同处置** | 市-县-乡三级联动的问题处置闭环 | 处置闭环率100% |
| **应急调度** | 快速响应的应急指挥调度体系 | 响应时间≤15分钟 |
| **数据驱动** | 燃气安全态势感知和决策支持 | 报表自动化率≥90% |

### 1.3 建设范围

- **覆盖区域**：松原市全域（宁江区、前郭县、长岭县、乾安县、扶余市）
- **监管对象**：3家燃气企业、200+场站、5000+km管网、50万+用户
- **用户群体**：市住建局、县区燃气主管部门、燃气企业、乡镇安监员、第三方服务机构

### 5.2 领域详细说明

**技术实现**：
- 基于 `yudao-module-iot` 实现设备管理和数据采集
- 使用 IoT 规则引擎实现报警触发
- 使用 WebSocket 实现实时推送
- 使用 Flowable 实现报警处置流程

**详细设计文档**：[plan/01-monitoring-domain.md](./01-monitoring-domain.md)

#### 5.2.2 巡查防控域（核心域）

**业务价值**：实现巡查工作的规范化、电子化管理，形成隐患发现-整改-验收闭环

**功能范围**：
- 周期规则配置（日/周/月巡查）
- 作业内容配置（检查项、标准）
- 流程节点配置（审批流程）
- 巡查计划制定与任务分派
- 巡查任务执行（移动端）
- 隐患上报与整改跟踪
- 疑难案件升级处理

**覆盖需求**：第26-28、44-59项，共19项

**技术实现**：
- 使用定时任务自动生成巡查任务

### 5.3 领域间交互关系

```
                                    ┌─────────────┐
                                    │  统计分析域  │
                                    │  (数据汇总)  │
                                    └──────┬──────┘
                                           │
                    ┌──────────────────────┼──────────────────────┐
                    │                      │                      │
                    ▼                      ▼                      ▼
            ┌───────────────┐      ┌───────────────┐      ┌───────────────┐
            │   监测预警域   │◄────►│   巡查防控域   │◄────►│   应急调度域   │
            │              │      │              │      │              │
            │ 报警触发预警  │      │ 隐患触发预警  │      │ 预警触发应急  │
            └───────┬───────┘      └───────┬───────┘      └───────┬───────┘
                    │                      │                      │
                    │                      │                      │
                    ▼                      ▼                      ▼
            ┌─────────────────────────────────────────────────────────────┐
            │                        资源管理域                            │
            │         企业 | 设施 | 专家 | 队伍 | 物资 | 设备              │
            └─────────────────────────────────────────────────────────────┘
                    │                      │
                    ▼                      ▼
            ┌───────────────┐      ┌───────────────┐
            │   督查检查域   │      │   安全培训域   │
            │  (监督企业)   │      │  (提升能力)   │
            └───────────────┘      └───────────────┘
```

**核心交互说明**：

1. **监测预警域 → 应急调度域**：当报警升级为预警时，触发应急调度流程
2. **巡查防控域 → 应急调度域**：当发现重大隐患时，可能触发应急响应
3. **监测预警域 ↔ 巡查防控域**：报警可能触发巡查任务，巡查可能发现设备问题
4. **所有领域 → 统计分析域**：各领域数据汇总到统计分析域进行分析
5. **所有领域 ← 资源管理域**：各领域依赖资源管理域的基础数据
